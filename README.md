### How the work gets found

[open-source-builder](https://github.com/manduinca/open-source-builder) is the
agentic system behind the list above. Claude Code agents discover active
projects in my domains, curate contribution opportunities from issues with
healthy communities, and report what is worth the time. The contributions are
the output; this is the method.
